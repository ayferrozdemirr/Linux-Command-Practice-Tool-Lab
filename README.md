# Linux Command Practice Tool

Bu proje, temel ve orta düzey Linux terminal komutlarını (dosya izinleri, chmod, grep, systemctl vb.) pratik yaparak öğrenmenizi sağlayan bir CLI (komut satırı) aracıdır.

## Dosya Yapısı
- main.py: Uygulamanın ana mantığını çalıştırır ve CLI arayüzünü sağlar.
- questions.json: Test sorularını ve seçeneklerini barındırır.
- README.md: Proje açıklama dosyası.
